# 🎁 盲盒抽背单词

把背不下来的单词随时加进来，盲盒式随机抽背：抽到就计次数、保证每个都抽到，自动发音 + 全词性全义项中文释义 + 例句；会了标熟、忘了还原。

## 使用

- 在线：https://wwweeee3632.github.io/vocab-blindbox/
- 本地：直接用浏览器打开 `index.html`（数据存本机浏览器）

## 功能

- 随时增量添加单词（空格 / 逗号 / 换行分隔，重复自动跳过）
- 盲盒抽取：没抽过的优先、抽过的按次数少的优先，保证均匀覆盖
- 自动发音（联网用真人音频，离线切浏览器 TTS），点 🔊 重听
- 内置离线中文词典（17365 词，全词性、全义项）
- 联网时自动补英文释义 + 例句
- 固定搭配靠每词的「🔗 固定搭配 / 笔记」栏手填，自动保存
- 标熟移入「已熟」、可一键还原
- 导出 / 导入备份，方便换设备迁移

## 词典重建

`dict.js` 由 `COCA_with_translation.txt` 生成（来源：`mahavivo/english-wordlists` 的 COCA 2 万高频词表）。

```bash
node build-dict.js
```
